|================|
|SW-Ausfälle	 |
|================|
- Node sendet Nachricht ohne zu empfangen (Geht in Failsafe, weil anderen Nodes nicht antworten => Sicherer Systemzustand)
- Node empfängt Nachrichten ohne zu senden (Wird ausgeschlossen, von den anderen Nodes durch seperate Message?)
- Node rechnet falsche Ergebnis / Verfälschtes Ergebnis durch bitflip (Voting setzt Suspect erst auf Suspect und dann Isolation)
- Node wählt falschen Voter (Voting setzt Suspect erst auf Suspect und dann Isolation)

- 1 Node fällt silent  => System rekonfiguriert und läuft weiter
- Mehrheit fällt silent => Failsafe durch letzten alive Node
- Node in probation fällt aus => System läuft weiter
- Healthy node fällt in probation vom anderen node aus => System unterschreitet gesunde Größe => Failsafe
